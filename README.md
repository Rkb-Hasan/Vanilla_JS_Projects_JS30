# Vanilla JS Projects — JavaScript30

A collection of hands-on projects built while working through **JavaScript30** by Wes Bos — a 30-day challenge focused on core JavaScript, the DOM, and CSS, with no frameworks or libraries.

## Projects

| #   | Project                                                                    | Focus                                    |
| --- | -------------------------------------------------------------------------- | ---------------------------------------- |
| 1   | [Drum Kit](./Drum%20Kit)                                                   | Event listeners, DOM manipulation        |
| 2   | [CSS JS Clock](./CSS%20JS%20Clock)                                         | Date object, setInterval, CSS transforms |
| 3   | [Array Cardio Day 1](./Array%20Cardio%20Day%201)                           | filter, map, sort, reduce                |
| 4   | [Flex Panel Gallery](./Flex%20Panel%20Gallery)                             | Flexbox, class toggling, transitions     |
| 5   | [Array Cardio Day 2](./Array%20Cardio%20Day%202)                           | some, every, find, findIndex             |
| 6   | [Fun with HTML5 Canvas](./Fun%20with%20HTML5%20Canvas)                     | Canvas API, mouse events                 |
| 7   | [Hold Shift & Check Checkboxes](./Hold%20Shift%20%26%20Check%20Checkboxes) | Event delegation, shift-click ranges     |

## Why this repo

Each folder is a self-contained project — its own `index.html`, `style.css`, and `script.js` — built to practice a specific set of vanilla JS/CSS concepts without relying on frameworks.
