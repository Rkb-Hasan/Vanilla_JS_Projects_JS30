# Array Cardio

A vanilla JS project from **JavaScript30** — a workout for JavaScript's built-in array methods, using a dataset of inventors and their birth/death years.

## What it does

A series of console-based exercises that filter, sort, transform, and query an array of objects — no UI, just practice flexing array methods in the console.

## Focus

- **filter()** — narrowing arrays down by a condition
- **map()** — transforming array items into new values
- **sort()** — ordering objects by a property
- **reduce()** — collapsing arrays into a single value
- **some() / every()** — testing arrays against conditions
- **find()** — grabbing a single matching item

## How it works

1. Start with an array of objects (e.g. inventors with `first`, `last`, `year`, `passed`).
2. Chain and combine array methods to answer specific questions — like "which inventors were born in the 1500s?" or "what's the total years all inventors lived?"
3. Log results to the console to check the output at each step.

## Tech

- Vanilla JavaScript (no frameworks, no libraries)
- Browser console

## Run it

Open `index.html` in your browser, then open the DevTools console to see the output.
