# Array Cardio Day 2

A vanilla JS project from **JavaScript30** — round two of array method drills, going further into some(), every(), find(), and findIndex().

## What it does

More console-based exercises using an array of inventors, testing conditions across the array and locating specific items.

## Focus

- **some()** — checking if at least one item matches a condition
- **every()** — checking if all items match a condition
- **find()** — retrieving the first matching item itself
- **findIndex()** — retrieving the index of the first matching item
- **splice() vs slice()** — mutating vs non-mutating array removal

## How it works

1. Start with the same array of inventor objects (`first`, `last`, `year`, `passed`).
2. Use `some()` and `every()` to answer yes/no questions — like "is at least one inventor still alive?"
3. Use `find()` and `findIndex()` to pull out a specific inventor or their position in the array.
4. Compare `splice()` and `slice()` to see the difference between mutating and copying arrays.
5. Log results to the console at each step.

## Tech

- Vanilla JavaScript (no frameworks, no libraries)
- Browser console

## Run it

Open `index.html` in your browser, then open the DevTools console to see the output.
